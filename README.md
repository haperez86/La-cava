# La Cava — Demo de gestión

Demo web de un sistema de gestión para restaurante.

## Módulos contemplados

- Roles: Administrador, Cajero y Mesero.
- Gestión de mesas, pedidos y comandas imprimibles.
- Caja, pagos y arqueo.
- Reportes mensuales exportables a Excel.
- Diseño adaptable a dispositivos móviles.

## Publicación

El sitio está preparado para publicarse como sitio estático con GitHub Pages. Cuando se agregue `index.html` a la raíz del repositorio, configura **Settings → Pages → Deploy from a branch → main → /(root)**.

> Esta documentación no sustituye el archivo funcional `index.html`; la demo aún debe subirse para que el sitio pueda ejecutarse.
